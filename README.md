# DyM Stickers

Sitio web desarrollado para **DyM Stickers**, un emprendimiento dedicado a la creación de stickers personalizados, tarjetería y papelería para emprendimientos, regalos, eventos y proyectos creativos.

Este proyecto fue realizado como parte de la **pre-entrega del curso Front End JS de Talento Tech**.

## 📌 Descripción de la pre entrega

La página web tiene como objetivo presentar los productos y servicios de DyM Stickers de una manera visual, clara y atractiva.

El sitio cuenta con diferentes secciones para que los usuarios puedan conocer el emprendimiento, visualizar algunos de los trabajos realizados, consultar por productos y enviar un mensaje a través del formulario de contacto.

## ✨ Secciones del sitio

* **Inicio:** presentación del emprendimiento y acceso al catálogo.
* **Productos:** muestra diferentes opciones de stickers y papelería.
* **Presentación:** información sobre DyM Stickers y la propuesta del emprendimiento.
* **Reseñas:** opiniones y experiencias de clientes.
* **Contacto:** información del emprendimiento y formulario para realizar consultas.
* **Footer:** navegación rápida por las diferentes secciones del sitio.

## 🛍️ Productos

Actualmente se presentan las siguientes categorías:

* Stickers personalizados.
* Tarjetería en general.
* Stickers holográficos.
* Stickers para regalos.

Las imágenes utilizadas corresponden a trabajos y productos de DyM Stickers.

## 📨 Formulario de contacto

El formulario permite ingresar:

* Nombre.
* Correo electrónico.
* Mensaje.

Para gestionar el envío de los formularios se utiliza **Formspree**, evitando la necesidad de desarrollar un servidor propio para recibir las consultas.

## 🎨 Diseño

El diseño utiliza una estética moderna y orientada al mensaje que busca DyM Stickers.

Se utiliza principalmente:

* Rosa.
* Blanco.
* Tonos claros.
* Tonos oscuros para contraste.

También se incorporan efectos `hover`, bordes redondeados, sombras y transiciones para mejorar la experiencia visual.

## 📱 Diseño adaptativo

El sitio está adaptado para diferentes tamaños de pantalla mediante **Media Queries**.

Se contemplan diferentes distribuciones para:

* Computadoras.
* Tablets.
* Celulares.

La navegación, las tarjetas de productos, las reseñas, el formulario y las diferentes secciones se reorganizan según el tamaño de la pantalla.

## 💻 Tecnologías utilizadas

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* Google Fonts
* Formspree
